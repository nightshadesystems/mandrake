NIGHTSHADE SYSTEMS — LOGO & ICON KIT
====================================

COLORS
  Nightshade accent #A78BE8
  Nightshade mid    #C7B4F0   (symbol facet fill)
  Nightshade tint   #EFE9FC
  Ink               #1F1A2E
  On-dark accent    #B9A4F2

TYPE
  Wordmark: Archivo Bold (Google Fonts), -0.02em tracking.
  Uppercase variant: Archivo SemiBold, 0.14em tracking.
  Support/mono: IBM Plex Mono.
  Lockup SVGs use live <text>; install Archivo, or outline the text
  in your editor before sending to print.

/logos
  nightshade-symbol-primary      accent outline + mid facet fill (default)
  nightshade-symbol-outline      accent outline, no fill
  nightshade-symbol-solid        solid accent, white facets
  nightshade-symbol-mono-ink     single-color ink
  nightshade-symbol-mono-white   single-color white (place on dark)
  nightshade-symbol-on-dark      accent tuned for dark backgrounds
  nightshade-appicon-*           128px rounded-square app icons
  nightshade-lockup-primary      symbol left + "Nightshade" wordmark right
  nightshade-lockup-on-dark      for dark backgrounds
  nightshade-lockup-reversed     white on accent field
  nightshade-lockup-mono-ink     one-color ink
  nightshade-lockup-uppercase    letterspaced NIGHTSHADE variant

/icons
  24px grid, 1.75px stroke, round caps and joins, ink #1F1A2E.
  Accent is reserved for meaning (allow, alert), not decoration.
  status-* are filled semantic badges.

CLEAR SPACE / MINIMUM SIZE
  Clear space = half the symbol height on all sides.
  Symbol min 16px. Full lockup min 120px wide; below that use the symbol.
