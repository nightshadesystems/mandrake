# ADR-0008: Console stack, generated client, and vendored design assets

- **Status:** Accepted
- **Date:** 2026-09-01
- **Phase:** 2 (Console shell)

## Context

Spec §8 fixes Vite, React, TypeScript, the Nightshade design system as the
only source of visual primitives, and a client generated from the OpenAPI
file. Spec §6.1 says the appliance serves its UI with zero external
dependencies. The design system export at
`nightshadesystems/design-system` is VMware Clarity re-skinned: CSS tokens
and classes, about fifty React components written in JSX with TypeScript
declaration files, Archivo and IBM Plex Mono loaded from Google Fonts, and
Clarity icons loaded from unpkg.

## Decision

- **Routing and server state:** `react-router` (data routes) and
  `@tanstack/react-query`. No global state library; server state lives in
  the query cache, UI state in components.
- **API client:** `openapi-typescript` generates `src/api/schema.d.ts` from
  `api/openapi.yaml` at build time; `openapi-fetch` is the only HTTP
  client, wrapped once in `src/api/client.ts` to add the CSRF header and
  map problem details to errors. ESLint keeps banning the global `fetch`.
- **Design system:** the export is copied into `console/design/` as-is:
  `tokens/`, `clarity/`, `components/` with their `.d.ts` files, and the
  brand assets. The JSX components are not rewritten to TypeScript; they
  are consumed through their declarations, and lint runs on
  `console/design/` with the type-aware rules relaxed. Pages and
  everything under `src/` stay strict. Re-exporting from upstream is a
  copy, never a hand edit, so drift is visible in the diff.
- **Fonts and icons vendored:** Archivo and IBM Plex Mono come from
  `@fontsource/archivo` and `@fontsource/ibm-plex-mono`; the Google import
  in `tokens/fonts.css` is replaced by those imports, the one edit made to
  the export. Clarity icons come from the `@clr/icons` package bundled by
  Vite. Nothing loads from a CDN.
- **Theme:** dark by default, `data-theme="light"` honoured and persisted
  per browser, as the design system already does.
- **API reference:** `docs/api.md` is generated by
  `console/scripts/gen-api-docs.mjs` from the OpenAPI file, committed, and
  checked in CI for staleness.

## Consequences

- `pnpm build` regenerates the client, so a contract change that breaks a
  page fails the build, which is the point.
- `@clr/icons` is deprecated upstream. It is what every exported component
  targets, so it stays until the design system moves; the swap is confined
  to `design/components/icon/`.
- Vendored fonts add roughly 400 KB of woff2 to the embedded assets.
- Relaxed lint under `console/design/` means bugs in the exported
  components are upstream's to fix in the design system, then re-exported.
